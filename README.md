# 灵感先行 · 卷轴制作预览 r05

依据 2026-11-04 的 v3 资源交接与导演稿 v2 制作。当前是可操作的制作候选；最终影片片尾、分享文案及资源领取文件仍可替换。

## 本机打开

双击 `启动预览.cmd`，或在此目录执行 `npm start`，打开命令输出的本机地址。需要 Node.js；不需要安装 npm 依赖。几何、字体、角色、产品、过程图和预览媒体均在本目录中，无 CDN 运行依赖。浏览器需要 WebGL2。

不要直接双击 index.html：浏览器的 file:// 安全规则会阻止 ES 模块和模型加载。

## 操作

1. 移动光标观察立体字；按住“按住，展开想法”约一秒。提前松开会退回。
2. 品牌、长按键和创作面板统一为工业细线、方角与深蓝平面；原底部两条提示保持删除。点击发送。窗口扩为 16:9，代码继续运行、渐黑，完整一秒黑场静音后自动开始影片。
3. 暂停、进度和声音控制同时管理影片与舞台。进度条可用鼠标或触屏拖动；拖动期间暂停采样，松开后保留拖动前的播放/暂停状态。影片的制作说明尾部仍可见，并明确标注待替换。新增“跳过影片”，经音画淡向白场、同位舞台拉出、Dot余韵/小号消散和离台进入卷轴；这是可审阅的预演衔接，最终FPV片尾仍待替换。
4. Dot 演出、余韵、小号消散和离台后，向下滚动浏览长卷。左侧可返回章节。
5. 点击过程卡片立起阅读；正文内滚动、画廊切换和对比分界线只影响当前卡片。点空白或“收起”返回。
6. 拖动玻璃方块观察六面；拖放流程板和工具；点击产品问题部位；三项交付完成后再拖印章。需要帮助时点 Dot 或“示范一步”。
7. 资源架上的书册、工具箱和工程盒可展开。领取内容尚未提供，均标“待补充”。

五关状态保存在当前浏览器独立存档键中。重试仅重置当前关；已完成结果不会触发自动换章。取消拖放或松在空白处不算错误。

r05继续遵照用户要求暂停舞台及舞台到卷轴修改，等待用户提供最新版本；1.5秒背景转换与活跃离台目标尚未实施。现有舞台编排、相机、音乐、播放逻辑与r02一致。

## 内容与媒体替换

- `src/config.mjs`：影片入口、显式待替换状态、舞台声音结束提示点和各章位置。
- `src/content.mjs`：五章文案、14 张过程卡片和三项资源的可替换内容。
- `assets/process/manifest.json`：16 张真实过程图片与原始来源记录。
- `assets/media/film-preview.mp4`：旧片的 720p / 60fps 网页压缩副本，完整 51.983333 秒、3119 帧，未裁剪片尾。来源与时间戳核对见 `preview-derivative.json`。199 MB 原片保留在提供的原始 ZIP，未覆盖。
- `assets/media/stage-placeholder.m4a`：旧舞台音乐；有声结束约 12.674 秒是对这份音轨的实测提示点，不是新片接点。

“设置”中可以选择本机新影片做当前会话预览。正式替换时应更新配置与媒体文件，并重新核对实际时长、音轨、FPV 白场、舞台表演和声音结束点。当前旧片末尾制作说明不是最终白屏，不以此候选宣称无缝片尾已验收。

## 可编辑结构

- `src/opening.mjs`、`src/opening-characters.mjs`：中文真实轮廓的浅厚度工程线条，以及192个真实ASCII薄字形，按32列×6行进行扫描、轻微三维剪切与同序收拢；均匀深蓝底，不使用金属、高光、投影或整字翻转。字符来自本机Consolas轮廓图形，未分发该字体文件；没有使用字符贴图、atlas或始终朝镜头的平面。
- `design-r03.css`：在原结构上统一工业线框/FUI视觉，取消厚重表面、圆角与阴影；保留44px主要触控区。`design-r02.css`提供沿用的布局。
- `src/main.mjs`：输入、单一画面状态机、相机、滚动与界面。
- `src/transport.mjs`：影片与舞台统一暂停、拖动事务、跳转、声音、静音和跳过过渡；所有媒体异步动作受同一代次约束，旧play/ended结果不会抢回状态。
- `src/scroll-space.mjs`：连续弯曲卷面、章节排版、卡片聚焦、工业线框与资源架机构。
- `src/resource-models.mjs`：r05资源架、书册、工具箱和分层工程盒的可编辑几何、材质与开合机构；保留原位置、标签和阅读内容。
- `src/resource-shelf.mjs`：真实L型截面立柱、折边层板、横梁、后撑、连接片与紧固件，按材料合并为5个网格。
- `src/space-utils.mjs`：按画布与空间几何的同一纵横比生成文字纹理，按字号等比适配；先等待本地字体就绪。
- `src/render-quality.mjs`：均衡档超采样、精细档、像素预算、慢帧回退与卷轴阴影稳定；不修改舞台时间轴。
- `design-r04.css`：移除重复覆盖场景的章节说明，给游戏控制文字提供独立底板。
- `src/dot-stage.mjs`、`src/dot-horn-dissolve.mjs`：同一个 D02、舞台、反射、表演、真实小号表面粒子、离台与陪伴。
- `src/games*.mjs`：五关几何、规则、实际产品、拖放、示范及存档。
- `assets/dot/`：完整认可 D02 共享组件与冻结资产，保持原有文件与依赖；不要用裸 GLB 替代。

## 已测试与边界

r05资源章覆盖三种宽度、三件物品的标签和实体点击、开合、阅读与返回。另复测手机六种入口和桌面背景关闭，修正触屏打开后兼容click立即关闭，以及Dot辅助点击范围挡住资源模型的问题。每件模型按201个开合姿态检查实际三角面与三层架板中平面，工具箱前抽修正后采样中无穿板；此为离散几何检查，并非任意场景碰撞系统。近景图使用同一实际模型，保留原网站灯光风格。

r04在1440×900、934×884、390×844三种视口中各抽样22个卷轴位置，检查文字、卡片、资源贴标、连接线和近裁面；检测范围内没有相交或越过近面后仍显示的卡片。98处文字纹理均在Idea字体加载后生成，纹理与几何纵横比最大误差0.342%（画布整数取整）；三种视口的卡片阅读、滚动锁定、收起及资源展开/归还通过。均衡档本机抽样约60fps；实际手机性能仍需实机核对。

在本机 RTX 3060 / ANGLE D3D11 / Chromium WebGL2 环境测试。主流程长按取消、聊天发送、纯黑静音、媒体暂停、卡片滚动隔离、聚焦返回和资源展开通过；r02三种视口复查黑场约1.018–1.019秒，r01截图另有逐RGB纯黑检查。五关真实鼠标完整操作在r01通过，r02保留规则并调整共享材质。舞台抽样及主卷轴抽样接近60fps；这不是所有设备、所有时刻的帧率保证。r02进度与跳过行为通过13项单测、23项浏览器检查。r03在三视口回归开场/发送/黑场/卷轴，并补测手机播放中拖住进度500ms及松手续播；无页面错误。

窄屏使用 390×844 触摸模拟进行布局与输入检查；尚未做真实手机、现场大屏及整条最终音轨的听感验收。模型问题是教学演示，不是完整机械骨架或精确产品故障仿真。过程图保留历史候选、参考图和修订记录的区别。

卡片升起后使用同一内容节点进入阅读层，保证原生滚动、触摸与对比滑杆可操作；收起前归还到原三维卡片。最终检查包含资源内滚、回顶、收回与再次展开，浏览器外层不会被自动滚偏。

## 构建与私密部署

`node build.mjs` 生成 `dist/`，排除旧片原始大文件与开发测试页。`.openai/hosting.json` 保留 Sites 私密站点的身份。用户已于 2026-11-04 明确授权将这份源码和素材部署至 `linggan-scroll-v3-kevin`；实际部署状态以交付的部署记录为准。站点保持仅所有者可访问，原始资源架仍未开放下载。部署复制排除原始大影片和角色包内未使用的历史预览模板，完整角色源码仍在源包保留。

Three.js 使用 MIT 许可；IdeaSans / Noto 字体许可与角色来源记录随资产保存。Shopify 页面和录屏仅用于空间与运动研究，未复制其品牌资产或源网站。
